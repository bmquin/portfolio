BlowingOffSteam

Built as a passion project, and to test our skills.

The purpose of this website is to create an app that encourages users to spend less time playing games on Steam by allowing them to compete against each other, while still holding each other accountable through leaderboards, streaks, visual statistics, and more.

Built using Next.js a frontend framework, Steam Web API to obtain user playtimes and access data from their steam accounts, and Neon Postgres as the database.
